# Mustervorlagen

Diese Dateien sind **geprüfte Referenzen**, keine automatische Wiederherstellung.

Regeln:

1. Niemals ungefragt über Nutzerdaten kopieren.
2. Bei Fehlern nur als Vergleich oder als bewusst gewählte neue Ausgangsdatei verwenden.
3. Jede Vorlage trägt die Schema-Version ihres Datenvertrags im Inhalt oder im Dateinamen.
4. Änderungen an Validatoren müssen gleichzeitig passende Vorlagen und Regressionstests aktualisieren.
5. Die intelligente Fehlerhilfe darf einen Vorlagenpfad empfehlen, aber keine produktive Datei still ersetzen.

Vorhanden:

- `config/config.v1.example.json`
- `version_registry/version_registry.v1.example.json`
- `events/events.v1.example.json`
- `todos/todos.v1.example.json`
