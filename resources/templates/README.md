# Versionierte Mustervorlagen

Diese Dateien sind **Referenzen**, keine automatischen Reparaturdateien. Sie dürfen niemals ungefragt über Nutzerdaten geschrieben werden.

Aktuelle Formate:

- `config/config.v1.example.json`
- `version_registry/version_registry.v1.example.json`
- `events/events.v1.example.json`
- `todos/todos.v1.example.json`
- `calendar/calendar.v1.example.json`
- `native_acceptance/native_acceptance.v1.example.json`
- `safe_file_sim/safe_file_preview.v1.example.json`

Für persistente Formate werden Vorlagen und Testdaten mit demselben Produktvalidator geprüft. Negative Fixtures liegen ausschließlich unter `testdata/` und gehören nicht ins Runtime-ZIP.
